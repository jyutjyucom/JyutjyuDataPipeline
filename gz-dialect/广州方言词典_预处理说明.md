# 广州方言词典 OCR 预处理指南

## 📋 概述

针对广州方言词典的图像特点（单页JPG、轻微泛黄、文字密集），我为你创建了专门的预处理工具，比原有的PDF处理工具更适合这个项目。

## 🔍 图像特点分析

- ✅ 已分割好的单页JPG图片
- ✅ 文字清晰度较好
- ⚠️ 纸张轻微泛黄
- ✅ 双栏排版，包含汉字和拼音注音

## 🛠️ 工具说明

### 1. 主预处理工具：`preprocess_guangzhou_dict.py`

这个工具提供了三种预处理模式：

| 模式 | 适用场景 | 特点 |
|------|----------|------|
| **light** | 图像质量好、字迹清晰 | 轻度处理，保留更多原始细节 |
| **balanced** (推荐) | 大多数情况 | 平衡处理，适合轻微泛黄的纸张 |
| **aggressive** | 图像质量差、对比度低 | 强力处理，包含去噪和锐化 |

### 2. 测试工具：`test_preprocess_modes.py`

帮助你对比不同模式的效果，选择最合适的参数。

## 📖 使用步骤

### 第一步：测试效果（重要！）

在批量处理前，先测试不同模式的效果：

```bash
python test_preprocess_modes.py
```

**配置说明**（编辑 `test_preprocess_modes.py`）：

```python
# 测试单张图片
SINGLE_TEST = True
SINGLE_IMAGE_PATH = "./廣州方言詞典/廣州方言詞典.白宛如.1993_image50_out.jpg"

# 或者测试多张样本
MULTIPLE_TEST = False
SAMPLE_INDICES = [1, 50, 100, 200, 300]
```

运行后会：
1. 生成对比图，显示原始图像和三种模式的效果
2. 保存所有版本到 `./test_comparison/` 目录
3. 提供模式选择建议

### 第二步：批量处理

确定最佳模式后，运行批量处理：

```bash
python preprocess_guangzhou_dict.py
```

**配置说明**（编辑 `preprocess_guangzhou_dict.py` 底部）：

```python
# 输入输出路径
INPUT_DIR = "./廣州方言詞典"
OUTPUT_DIR = "./廣州方言詞典_preprocessed"

# 处理模式（根据测试结果选择）
MODE = "balanced"  # 可选: light / balanced / aggressive

# 输出格式
OUTPUT_FORMAT = "png"  # 推荐PNG，质量更高；也可选"jpg"

# 是否跳过已存在的文件
SKIP_EXISTING = True

# 可选：只处理部分文件
START_FILE = None  # 例如: "image50"
END_FILE = None    # 例如: "image100"
```

### 第三步：进行OCR

预处理完成后，使用预处理后的图片进行OCR：

```bash
python OCR.py
```

记得在 `OCR.py` 中将输入路径改为预处理后的目录：
```python
INPUT = "./廣州方言詞典_preprocessed"
```

## 🎯 推荐流程

根据你的图片特点，我的建议：

1. **首选方案（推荐）**：使用 **balanced** 模式
   - 原因：你的图片质量较好，只是轻微泛黄
   - 该模式可以提升对比度，同时保持文字清晰度

2. **备选方案**：直接使用原图
   - 如果测试发现预处理效果不明显或反而变差
   - 你的图片本身质量已经很好，可能不需要预处理

3. **不推荐**：aggressive 模式
   - 除非发现某些页面特别模糊或有噪点

## ⚙️ 高级自定义

如果预设模式都不满意，可以自定义参数：

```python
from preprocess_guangzhou_dict import preprocess_for_ocr

# 自定义参数
custom_params = {
    "brightness": 1.1,      # 亮度因子
    "contrast": 1.3,        # 对比度因子
    "clahe_clip": 2.0,      # CLAHE限制值
    "clahe_grid": (12, 12), # CLAHE网格大小
    "sharpen": False,       # 是否锐化
    "denoise": False        # 是否去噪
}

processed_img = preprocess_for_ocr(
    "input.jpg", 
    mode="custom", 
    custom_params=custom_params
)
```

## 🐛 常见问题

### Q1: 需要安装额外的依赖吗？
A: 不需要，所有依赖已在 `requirements.txt` 中。如果缺少，运行：
```bash
pip install opencv-python pillow numpy matplotlib tqdm
```

### Q2: 处理658张图片需要多久？
A: 取决于你的电脑性能，大约5-15分钟。

### Q3: 输出PNG还是JPG？
A: 推荐PNG，因为：
- PNG无损压缩，OCR效果更好
- 文件稍大，但对658张图来说可以接受
- 如果空间紧张，可以选JPG（quality=95）

### Q4: 预处理后OCR效果会提升多少？
A: 根据经验：
- 质量好的图片：提升5-10%
- 泛黄或对比度低的图片：提升15-30%
- 建议先用几张图片测试对比
